//PingAnalyzer  
PingAnalyzer – многопоточная консольная утилита для мониторинга доступности хостов (ping) и сбора статистики использования ресурсов (CPU, RAM, диск C:) через WMI. Программа работает в реальном времени, проверяя хосты с заданными интервалами, и сохраняет результаты в файлы. При обнаружении проблем (недоступный хост или загрузка диска >80%) выводит всплывающее окно с предупреждением.  
//Возможности  
Параллельный ping всех хостов из списка.  
Сбор ресурсов (CPU, RAM, диск C:) для локальных и частных IP-адресов (RFC 1918 и localhost).  
Динамическое изменение интервалов – программа перечитывает config.txt каждую секунду, изменения вступают в силу без перезапуска.  
Дозапись данных в hosts.txt – вы можете добавлять новые хосты в файл во время работы, они будут обработаны при следующей итерации (ping или сбор ресурсов).  
Автоматическое логирование – все результаты сохраняются в ping_results.txt0 и resource_stats.txt.    
Предупреждения через MessageBox при недоступности хостов или критической загрузке диска (>80%).  
//Требования  
Операционная система Windows (используются WinAPI, WMIC).  
Компилятор с поддержкой C++ (Visual Studio, MinGW).  
Права на выполнение WMIC-запросов (для локального и удалённого доступа).  
//Компиляция и запуск  
С помощью Visual Studio  
Откройте файл решения PingAnalyzer.sln.  
Локальный отладчик Windows.  
Далее запустится программа и откроется консоль, в котором будут видны результаты ping и сбора ресурсов.  
С помощью командной строки (cmd)  
cd C:\путь\к\папке\с\программой  
PingAnalyzer.exe  
PowerShell  
cd C:\путь\к\папке\с\программой  
.\PingAnalyzer.exe  
//config.txt – интервалы проверок  
ping_interval – интервал (в секундах) между запусками проверки доступности хостов.  
resource_interval – интервал (в секундах) между сборами статистики ресурсов.  
Программа перечитывает config.txt каждую секунду (в основном цикле).  
Вы можете изменить интервалы, не останавливая мониторинг. Например, увеличить ping_interval до 120 – новые значения будут применены сразу после сохранения файла.  
Если файл отсутствует или содержит некорректные значения, используются значения по умолчанию (60 секунд).  
Пример записи в файл:  
ping_interval 60  
resource_interval 60  
//hosts.txt – список хостов для мониторинга  
хост – IP-адрес или доменное имя (обязательное поле).  
логин и пароль – опциональны, используются только для доступа к WMI на удалённом хосте. Для локального мониторинга их можно опустить.  
Пример записи в файл:  
<хост> [логин] [пароль]  
8.8.8.8 admin 1234  
//Запись результатов программы в отдельные файлы  
Результаты PING сохраняются в файл ping_results.txt  
AVAILABLE - хост ДОСТУПЕН  
UNAVAILABLE - хост НЕДОСТУПЕН  
Результаты сбора ресурсов сохраняются в файл resource_stats.txt  
Коды ошибок в resource_stats.txt  
PUBLIC_HOST – IP-адрес публичный. Ресурсы для таких хостов не собираются.  
HOST UNREACHABLE – хост не отвечает на ping (сеть недоступна).  
CPU:ERROR/RAM:ERROR/DISK_C:ERROR – не удалось получить соответствующий параметр (нет прав, таймаут, хост не Windows, отключён WMI).  
THREAD ERROR – системная ошибка при создании потока (редко).  
UNKNOWN – неожиданная ошибка; обычно не встречается.  
Подробные причины ошибок WMI записываются в wmi_errors.log.
